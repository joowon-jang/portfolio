02 / INDEPENDENT PROJECT

AioLM

로컬 LLM 실측 데이터를 공유해
기기 구매와 실행 환경 선택을 돕는
데스크톱 앱 · 웹 서비스.

벤치마크 · 입력 길이와 동시 요청 수화면 원본 ↗
모델 설정 · GPU 레이어와 배치 크기화면 원본 ↗
벤치마크 웹사이트 ↗데스크톱 앱 저장소 ↗웹 저장소 ↗

기획부터 데스크톱 앱과 웹사이트 개발까지 맡은 개인 프로젝트입니다. 앱에서는 모델·런타임 관리와 로컬 추론, 벤치마크를, 웹에서는 공개 결과의 검색·상세·비교를 구현했습니다.

입력 길이와 동시 요청 수가 같은 측정 지점을 비교하고 모델·기기·런타임 정보를 함께 표시합니다. Windows 앱과 웹사이트를 공개했으며, 지속 개선 중입니다.
