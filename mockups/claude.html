AioLM

로컬 LLM 실측 데이터를 공유해 기기 구매와 실행 환경 선택을 돕는 데스크톱 앱·웹 서비스

역할
기획·데스크톱 앱·웹사이트 개발

AI에 대한 관심으로 여러 기기를 자비로 구입하고, 다양한 환경에서 LLM의 추론과 파인튜닝을 배워왔습니다. 근무처의 다른 팀과 기술 커뮤니티에서 성능 정보가 부족해 기기 구매나 설정에 어려움을 겪는 사람들을 보았습니다.

실측 결과를 공유해 구매와 설정 판단을 돕고자 AioLM을 개발·공개했으며, 현재도 개선하고 있습니다.

두 개의 제품

  • 데스크톱 앱llama.cpp 기반 모델 실행·채팅·튜닝·벤치마크
  • 웹사이트공개된 벤치마크 결과를 모델·기기·측정 조건별로 탐색·비교

사용 흐름 Flow

  1. 모델·런타임 선택
  2. 입력 길이·동시 요청 수 설정
  3. 로컬 벤치마크 측정
  4. 사용자가 결과 공개 여부 선택
  5. 웹에서 조건별 탐색·비교

핵심 사용자 경험 Features

다양한 로컬 실행 환경

GGUF 모델과 CPU·Vulkan·ROCm·CUDA·SYCL·OpenVINO 런타임을 관리하고 실행 설정을 조정

조건을 기록하는 벤치마크

입력 길이·동시 요청 수별 TTFT·생성 속도·프로세스 RAM 등 실측값과 실행 환경을 함께 기록

공개 결과 탐색과 비교

모델·하드웨어·실행 환경으로 필터링하고 최대 3개 결과를 비교하며, 측정 방식이나 부하가 다르면 비교 유의사항 표시

계정 없이 결과 관리

복구 코드·복구 파일 또는 앱에서 웹으로 이어지는 일회성 연결을 이용해 공개 결과의 설명을 수정하거나 삭제

  • 측정 조건을 고려한 결과 비교

    입력 길이와 동시 요청 수가 같은 지점의 값을 비교합니다. 모델·기기·런타임 정보를 함께 표시하고, 측정 방식이나 부하가 다르면 안내합니다.

  • 벤치마크 설정 분리와 측정값 검증

    채팅 설정과 분리된 전용 서버에서 캐시 재사용 없이 측정합니다. 실제 토큰 수를 검증하고 실패한 측정은 평균에서 제외합니다.

  • 앱과 웹의 데이터 규칙 통일

    검증 규칙과 OpenAPI 스키마를 benchmark-contracts 패키지로 공유합니다.
