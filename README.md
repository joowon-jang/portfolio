# JOOWON.EXE — 포트폴리오

레트로 픽셀(게임 UI) 컨셉의 프론트엔드 개발자 포트폴리오. 빌드 도구 없는 순수 정적 사이트입니다.

## 실행

```bash
npx serve .
# 또는
python3 -m http.server 8080
```

파일을 직접 열어도(`index.html` 더블클릭) 동작합니다.

## 인쇄

브라우저의 인쇄 기능으로 현재 보고 있는 홈 또는 프로젝트 상세 페이지를 인쇄하거나 PDF로 저장할 수 있습니다. 화면의 어두운 색상과 주요 UI를 유지하며, 용지 크기와 페이지 나눔에 맞춰 일부 배치를 조정합니다. 상세 스크린샷은 원본 비율로 표시하고 동영상은 대표 이미지로 대체합니다. 브라우저의 인쇄 설정에서 **배경 그래픽**을 켜면 화면과 같은 배경색을 출력할 수 있습니다.

## 구조

- `index.html` — 셸(내비게이션, 폰트, 스크립트 로드)
- `css/style.css` — 전체 스타일 + 태블릿/모바일 반응형 레이아웃
- `js/data.js` — 콘텐츠 데이터 (ko/en/ja i18n, 프로젝트, 링크, 연락처)
- `js/app.js` — 프로젝트 데이터 기반 해시 라우팅(`#p1`~`#p4` 상세 페이지), 언어 전환, 성과 HUD, 접근 가능한 모바일 메뉴

## 콘텐츠 수정

모든 텍스트는 `js/data.js`에 있습니다.

- **경력**: `careers[] → projects[] → contributions[]` 구조로 프로젝트별 기여를 기록하고, 프로젝트에 묶지 않는 업무는 회사의 `contributions[]`에 별도로 기록합니다. 회사의 주요 업무를 프로젝트보다 먼저 표시하며, `featured`와 `summary`로 강조 항목과 접힌 상태의 요약을 지정합니다. 프로젝트의 `stack`은 기술 스택, 각 기여의 `title`과 선택적인 `outcome`은 항상 표시하고 `desc`(문자열 또는 불릿 배열)는 펼쳐 볼 수 있습니다. 인쇄 시 상세 내용도 모두 표시합니다. ko/en/ja 내용을 함께 갱신합니다.
- **이미지**: `js/data.js`의 `IMAGES`에 경로를 넣으면 플레이스홀더가 교체됩니다.
  (`photo`, `thumb-p1`~`thumb-p4`, `shot-p1-1` 등)
- **AioLM (`p4`)**: `AIOLM`에 ko/en/ja 소개를 정의합니다. `motivation`은 개발 배경이며, 개발 기여와 구분합니다. 실제 앱의 벤치마크·모델 설정 화면을 `assets/projects/aiolm/`에 저장했습니다. `screenshotLayout: 'wide'`는 이미지를 자르지 않고 한 열로 표시하며 원본 링크를 제공합니다.
- **프로젝트 링크**: `LINKS`에 실제 배포/저장소 주소가 반영되어 있습니다. (토도동 배포는 운영 종료로 저장소 링크만 유지)

프로필과 프로젝트 이미지는 `assets/`에 저장되어 있으며, 블로그 글은 `BLOG_POSTS`에서 연결합니다.
